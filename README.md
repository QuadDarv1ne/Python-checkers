## Описание проекта
Игра Шашки, написанная на Python с использованием графической библиотеки Tkinter.

В игре присутствует экспертная система, представленная алгоритмом для нахождения оптимального хода у вражеских шашек.

Разработка велась на Python 3.9.7

### Возможности

- Четыре уровня сложности: Лёгкий, Средний, Сложный, Гроссмейстер
- Выбор стороны: играть за белых или за чёрных
- Три варианта правил: русские, международные (турецкий удар), английские (чекерс)
- Звуковые эффекты и фоновая музыка (синтезируются на лету, без внешних файлов)
- Регулировка громкости, отдельные переключатели эффектов и музыки
- Подсказка лучшего хода, отмена хода, подсветка ходов под курсором
- Переворот доски и координаты a–h / 1–8 вокруг поля
- Панель истории ходов с нотацией и переходом по позициям
- Две темы оформления (классика и тёмная), доска масштабируется вместе с окном
- Свой курсор над доской: наборы Minimalistic V5, Oreo и Glib, перекраска в любой цвет
- Горячие клавиши и сохранение настроек между запусками

### Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python main.py
```

Самопроверка логики без показа окна:

```bash
python tools/selfcheck.py
```

### Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` | Новая игра |
| `Ctrl+R` | Начать заново |
| `Ctrl+Z` | Отменить ход |
| `Ctrl+H` | Подсказка |
| `Ctrl+F` | Перевернуть доску |
| `Ctrl+←` / `Ctrl+→` | Предыдущая / следующая позиция истории |
| `Ctrl+S` | Звуковые эффекты |
| `Ctrl+M` | Музыка |
| `Esc` | Скрыть подсказку |
| `F1` | Справка по клавишам |
| `Ctrl+Q` | Выход |

### Наборы курсоров

Готовые наборы лежат в `assets/cursors` (PNG + `meta.json` с hotspot). Меню
`Вид → Курсор → Набор` переключает Minimalistic V5, Oreo, Glib или векторный
курсор, а `Вид → Курсор` меняет цвет — от «как в наборе» до любого оттенка
палитры. Наборы собраны из архивов в `cursors/` скриптом:

```bash
python tools/build_cursor_packs.py
```

Скрипт разбирает `.cur`/`.ani`, обрезает прозрачные поля и пересчитывает
hotspot, поэтому игре не нужны бинарные форматы Windows. Архивы `.zip`/`.rar`
кладутся в `cursors/` (в git они не попадают), `.rar` распаковывается через
`UnRAR.exe` из WinRAR.

Источники наборов: [Minimalistic V5](https://vsthemes.org/cursors/neon/76118-minimalistic-v5.html),
[Oreo](https://vsthemes.org/cursors/static/18096-oreo.html). Условия
использования — на страницах авторов, в архивах есть PDF с описанием.
